Meme Generator

A simple meme generator built with HTML, CSS, and JavaScript.

Features
Browse a gallery of images
Add and edit text on memes
Change text color
Increase and decrease font size
Add multiple text lines
Switch between text lines
Select a text line directly on the canvas
Download the finished meme
Responsive design for desktop and mobile
Technologies
HTML
CSS
JavaScript
Canvas API
